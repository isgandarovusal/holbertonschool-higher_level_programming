# Python - Serialization

## Təsvir
Bu layihə məlumatların seriyallaşdırılması (serialization) və marşalinq (marshaling) konseptlərini əhatə edir. Layihə çərçivəsində müxtəlif formatlarda (JSON, Pickle, CSV, XML) məlumatların saxlanılması, ötürülməsi və yenidən bərpa edilməsi öyrənilir.

## Öyrənmə Məqsədləri
* Marşalinq və Seriyallaşdırma arasındakı fərqləri anlamaq.
* Python-da məlumat strukturlarını fayllara yazmaq və oxumaq.
* JSON, Pickle və digər formatların performans və təhlükəsizlik fərqlərini qiymətləndirmək.
