# Python - Test Driven Development

## Description
This project focuses on the importance of **Test Driven Development (TDD)** in Python. The goal is to write high-quality code that is validated by thorough documentation and test cases using the `doctest` module.

## Requirements
* All files are interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
* All files should end with a new line
* The first line of all files should be exactly `#!/usr/bin/python3`
* Code must follow the `pycodestyle` (version 2.8.*)
* All modules, classes, and functions must have documentation (`__doc__`)
* All tests are executed using the command: `python3 -m doctest -v ./tests/file.txt`

## Tasks

### 0. Integers addition
* **File:** `0-add_integer.py`, `tests/0-add_integer.txt`
* **Description:** A function that adds two integers or floats.
* **Logic:** * Validates that inputs are integers or floats.
  * Handles edge cases like `NaN` and `Infinity`.
  * Casts floats to integers before addition.
